# Java Project 🚀

A beginner-friendly Java project containing basic Java programming concepts and a simple calculator application. This project is created for practicing Java syntax, classes, methods, input handling, and basic programming logic.

## 📌 Projects Included

### 1. Main Java Program

`Main.java` contains the main Java program and demonstrates fundamental Java programming concepts.

### 2. Calculator

`calculator.java` is a simple calculator program that performs basic arithmetic operations.

**Operations include:**

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/yujal12/Java-project.git
```

### Step 2: Open the Project

```bash
cd Java-project
```

### Step 3: Compile the Main Program

```bash
javac Main.java
```

### Step 4: Run the Main Program

```bash
java Main
```

### Run Calculator

```bash
javac calculator.java
java calculator
```
